Breadboard 6502 8-Bit Computer

This is based on Ben Eater’s YouTube series. Creating it was a lot of fun, with the biggest challenge being the wire routing on the breadboard.

Components
  • Adjustable clock and attendant circuitry
  • 65C02 — a static 6502 that retains its state even when the clock is stopped
  • 65C22 VIA for I/O
  • 16×2 LCD display
  • 32K EEPROM
  • 32K SRAM
  • Wires for address and data bus

Using an EEPROM programmer I was able to write programs directly, as I was already familiar with 6502 opcodes.

Future Plans

What I was not able to accomplish — but still think about — is using a Raspberry Pi Pico to emulate memory-mapped devices by programming the PIO state machines. The real problem is that I needed one or two more GPIO pins to have sufficient address space, chip select, R/W, and 8 data pins.

I want to implement a video display that translates 6502-generated bitmaps to the Raspberry Pi display, and a storage device so I can update code from the Raspberry Pi without needing to burn the EEPROM each time.
